# Карточка товара Teaboom.ru

Тестовое задание: верстка карточки товара «Ананасовый улун»

## Что реализовано

- Изображение товара из `assets/images` с бейджем «Скидка!», миниатюрами и увеличением в lightbox
- Название товара, категория и хлебные крошки
- Выбор фасовки: 100 г, 500 г, 1000 г, 5000 г
- Обновление артикула, актуальной цены и старой цены при смене фасовки
- Кнопка «В корзину» с временным состоянием «Добавлено!»
- Блок советов, похожие товары и табы «Описание / Свойства / Отзывы»
- Адаптивность для desktop, tablet и mobile, включая ширину 375px

## Запуск

### Без сборки

Откройте `index.html` в браузере. Файл `css/main.css` уже скомпилирован и подключен в HTML

### Через локальный сервер

```bash
npm install
npm start
```

Локальный сервер будет доступен по адресу, который покажет команда `serve` в терминале

## Работа со стилями

Исходные стили находятся в `scss/`. Файл `css/main.css` является скомпилированным результатом и нужен, чтобы проект можно было открыть без дополнительной сборки

Если менялись SCSS-файлы, нужно пересобрать CSS:

```bash
npm run build:css
```

Для разработки можно запустить наблюдение за SCSS:

```bash
npm run watch:css
```

## Структура проекта

```text
├── index.html              # HTML-разметка карточки
├── scss/
│   ├── _variables.scss     # переменные: цвета, размеры, брейкпоинты
│   └── main.scss           # исходные стили
├── css/
│   ├── main.css            # скомпилированный CSS
│   └── main.css.map        # sourcemap для CSS
├── js/
│   ├── product-data.js     # данные продукта: фасовки, цены, советы, описание, свойства
│   └── main.js             # интерактив: фасовки, lightbox, табы, карусель
├── assets/
│   └── images/             # изображения товара и фон
├── package.json            # npm-скрипты
├── package-lock.json        # зафиксированные версии зависимостей
└── README.md
```
